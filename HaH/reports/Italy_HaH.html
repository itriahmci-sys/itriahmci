03居家住院：不是居家護理，是「住院」搬到家裡

居家住院（Ospedalizzazione a Domicilio, OAD；Hospital at Home）收治的是「本來應該住院」的急性病人，例如肺炎、心衰竭急性惡化。差別在於病床換成自家的床，醫療責任仍然歸醫院。

05分層負責制度：誰出錢、誰開藥、誰半夜接電話

居家住院最常被問的問題是：「出事了誰負責？」CANP 的經驗可以拆成七個層次。核心原則只有一句：研發計畫的責任與臨床醫療的責任分開。企業夥伴負責把系統做出來、讓設備能用；病人的醫療決策與法律責任始終留在醫院。

設備告警呢？公開資料沒有說明夜間誰接收穿戴裝置或遠距監測的告警。ADAMO 手錶研究階段的資料是自動存檔，事後由研究與醫療人員檢視[21]，因此不能假設「戴了手錶，跌倒就會有人立刻趕來」。

為什麼重要？如果系統 24 小時產生資料，但人力只排 12 小時，夜間就會出現「有資料、沒人看」的空窗。任何移植 CANP 模式的地方，都要先把這段寫清楚。

06AAL 架構：替居家住院裝上「數位神經系統」

AAL（Ambient Assisted Living，環境輔助生活）常被想成「家裡裝感測器」。CANP 的定義寬得多：它把居家環境、醫療設備、臨床團隊和醫院資訊系統視為同一個服務生態系[12]。

比喻：郵局的分信中心

Kafka 像一座分信中心。每台設備把信（JSON 訊息）投進自己的信箱（topic），誰需要就去訂閱。寄件者不必認識收件者，新系統加入時只要多訂一個信箱，不用改動既有設備。這就是「鬆耦合」，也是 CANP 避免被單一廠商綁住的設計。

但信送到了，不等於有人讀了

系統能發出「資料已異動」的通知，卻無法證明臨床人員已經簽收、評估並回寫處置。這三件事要分別留下紀錄。另外，使用 JSON 和 REST API 不代表採用 HL7 FHIR；架構論文中並未提到 FHIR 或 HL7[12]。

10成效與證據：我們到底知道多少？

CANP 的學術產出豐富，但大多屬於流程分析、架構設計、個案報告與單組觀察。截至目前，尚未查得針對整個整合平台的隨機對照試驗或完整成本效益分析。

① 流程分析與模擬

以 Molinette 居家住院的真實事件日誌，進行 BPMN 建模、離散事件模擬與流程探勘，找出收案瓶頸並模擬導入遠距設備後的人力負荷[13][14][15]。

事件驅動 AAL 架構[12]；以 BPMN 結合 DDL 半自動檢核部分 GDPR 規則[16]；以三年期專案建立 PDCA 式 IT 風險評估框架[17]。

11可移植的經驗與落地風險

想借鏡 CANP，最值得帶走的不是某支手錶或某個 App，而是一套工程方法：既有的居家住院臨床量能 ＋ 先看清流程 ＋ 事件驅動的整合平台。

🔍 先分析流程，再導入科技

用 BPMN 與流程探勘找出收案、訪視、出院的真實瓶頸，再決定科技介入點[13][14]。

👩‍⚕️ 讓第一線參與設計

GoCare 透過跟班觀察與參與式工作坊迭代，目標是減少排程與協調負擔[23]。

🔌 鬆耦合整合異質資料

以事件管理器串接不同廠商設備與醫院資料，降低資料孤島與廠商鎖定[12]。

🏡 把 AAL 當服務生態系

串起居家環境、照顧者訓練、設備商、臨床團隊與資訊系統[12][18]。

🔒 隱私與合規內建

設計階段即導入 GDPR 邏輯檢核與 IT 風險控制[16][17]。

⚖️ 分清計畫責任與臨床責任

技術夥伴交付系統，醫院承擔醫療的法律與財務責任[24]；這條線劃清楚，合作才走得久。

五項落地風險

風險為什麼會發生可以怎麼防
資料互通公開文獻未證實 FHIR 等國際標準在正式環境落地，新增設備或對接其他醫院 HIS 可能需要大量客製在採購規格中明訂標準 API 與術語代碼
警訊疲勞連續監測資料大量湧入，若無分級閾值、過濾與回應時限，容易「有資料、無人處置」先定義誰看、多久內看、看完做什麼，再擴大監測
夜間與跨機構責任團隊 08–20 運作，夜間轉由緊急服務；設備告警與交接若無書面協議，易生爭議建立夜間告警路由、交接紀錄與隔日接回流程
財務永續研發補助有期限；若平台與監測未納入常規給付，示範結束後難以維持試辦期間同步蒐集成本資料，規劃給付項目
設備全生命週期穿戴裝置需要校準、充電、清消、物流回收與資安修補，公開資料未揭露規模化後的後勤體系把維運責任寫進合約，含資安事件通報時限

解讀限制

1. 區域試辦 ≠ 全國制度

CANP 是皮埃蒙特大區的研發計畫，不應等同義大利全國的居家住院標準[1][9]。

2. 數位化是疊加，不是從零開始

服務自 1985 年運作，許多成效來自成熟的臨床組織，不能全歸功於科技[24]。

3. 技術揭露多，治理揭露少

資料管線寫得很細，警訊閾值、夜間人力、FHIR 對應與給付費率幾乎未公開。

4. 機構與時程變動

領銜企業已併入 ALTEN Italia，補助調整延續到 2023 年，兩份名冊的起訖日期也不一致[4][7][9][11]。
